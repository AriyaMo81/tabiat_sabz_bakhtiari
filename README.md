# Laravel E-Commerce

یک پروژه کامل فروشگاه اینترنتی توسعه‌یافته با **Laravel** که با هدف پیاده‌سازی قابلیت‌های واقعی یک فروشگاه آنلاین و تمرین مفاهیم مهم توسعه وب طراحی شده است.

این پروژه شامل مدیریت محصولات و دسته‌بندی‌ها، احراز هویت کاربران، سبد خرید، علاقه‌مندی‌ها، کدهای تخفیف، پرداخت آنلاین، پروفایل کاربر، پنل مدیریت، نقشه و نمودارهای آماری است.

## ⚙️ Installation

ابتدا Repository را Clone کنید:

```bash
git clone https://github.com/AriyaMo81/tabiat_sabz_bakhtiari.git
```

و وارد پوشه پروژه شوید:

```bash
cd tabiat_sabz_bakhtiari
```

وابستگی‌های PHP را نصب کنید:

```bash
composer install
```

وابستگی‌های Frontend را نصب کنید:

```bash
npm install
```

فایل `.env` را ایجاد کنید:

```bash
cp .env.example .env
```

سپس Application Key را ایجاد کنید:

```bash
php artisan key:generate
```

اطلاعات دیتابیس را در فایل `.env` وارد کنید.

سپس Migrationها را اجرا کنید:

```bash
php artisan migrate
```

در صورت وجود Seeder:

```bash
php artisan db:seed
```

برای ساخت لینک Storage:

```bash
php artisan storage:link
```

برای اجرای Vite:

```bash
npm run dev
```

و برای اجرای پروژه Laravel:

```bash
php artisan serve
```

پروژه معمولاً از طریق آدرس زیر قابل دسترسی است:

```text
http://127.0.0.1:8000
```

## 🔐 Environment Variables

قبل از اجرای پروژه، مقادیر مورد نیاز در `.env` را تنظیم کنید.

نمونه موارد مهم:

```env
APP_NAME=Laravel
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=database_name
DB_USERNAME=root
DB_PASSWORD=
```

برای امکاناتی مانند SMS، درگاه پرداخت، نقشه و سایر سرویس‌های خارجی نیز باید API Key و اطلاعات مربوط به سرویس موردنظر در `.env` قرار گیرد.

> فایل `.env` به دلیل داشتن اطلاعات حساس نباید در GitHub قرار بگیرد.
